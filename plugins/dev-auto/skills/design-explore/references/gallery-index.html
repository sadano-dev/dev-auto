PROJECT デザイン検討

現行デザイン（00）を基準に、方向性の異なる N 案を同じ内容・同じ画面（画面 A / 画面 B）で並べました。フィクスチャの説明（難しい場合を含むこと）。各案の上部に「トークンファイルとの差分」と「アクセシビリティ上の注意」があります。気に入った要素を案をまたいで組み合わせる前提で見てください。
